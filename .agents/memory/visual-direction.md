description: User-selected visual style for Slice & Bloom

The user selected **Arcade Pop** for Slice & Bloom's UI refresh.

**Why:** They chose this visual direction explicitly from the offered style cards.

**How to apply:** Keep future UI additions consistent with the bright, bold, playful arcade direction unless the user requests another style.

Do not frame the play area as a phone screen.

**Why:** The user explicitly requested removing the phone-shaped play-area frame so gameplay uses more screen space.

**How to apply:** Let scenery fill the available gameplay region without a device-like border, while preserving puzzle proportions and accurate touch mapping.
